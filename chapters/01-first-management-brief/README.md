# Chapter 1 — first management brief

**Tools:** a document and an ordinary chatbot. No code or GitHub access is needed.

## Start

Copy the five [Chapter 1 records](../../acme-practice-packet/records-chapters-1-3.md#chapter-1--first-management-brief) into your document. Before prompting, answer: What can I state with confidence? Which decisions block a credible plan? What should happen before the next status review?

## Exercise

Ask the assistant for confirmed facts with source days, unresolved questions, dependencies and consequences, decisions and possible owners, a concise weekly status draft, and a list of facts to verify before sending. Tell it to distinguish evidence from interpretation and to invent no date, capacity figure, approval, or delivery commitment. Compare its answer with your own.

Then make the chapter's **counterfactual change**: replace Alpha's Monday note with the approved-Wednesday note in the packet. Rerun the same prompt. Does the assistant distinguish an approval claim from Bravo's readiness to use the new version?

## Check the result

- Bravo cannot finish full integration sizing from the original packet; independent interface work can be estimated.
- The 25% figure is a proposed target without an agreed baseline or method.
- Capacity is provisional; a delivery date is not established.
- In the variation, confirm Bravo's acknowledgement and impact before calling the blocker resolved.

Save your own assessment, both outputs, and the final prompt. Compare your report format with the [illustrative samples](../../acme-practice-packet/reporting-samples.md), but remember that those samples use the later Chapter 4 snapshot.
