# Chapter 15 — Your First 90 Days as an Agentic PM

The Acme story has reached a working but still bounded system. This final chapter turns its method into a 90-day pilot plan. The [local example](example/README.md) starts with a **fictional** weekly-status task and the Chapter 14 illustrative value result. It checks whether a pilot charter has enough evidence and guardrails to proceed to human review. It never grants access, deploys a system, or publishes a report.

## Work in the chapter's cadence

1. Days 1–30: choose one narrow problem, name an owner, record a baseline, and define an accepted output. Inspect [case A](example/fixtures/pilot-cases.json) and write your own charter before using the program.
2. Days 31–60: use an approved read-only source, compare paired manual and assisted tasks, and keep a person in the review loop. Run cases B, C, and D to see what happens when the baseline, access boundary, or target is missing.
3. Days 61–90: test stop conditions and the full cost of operation. Run case E, then compare the plan with the [sample output](example/sample-plan.md). A favorable projection is not permission to expand autonomy.
4. Use the [reader prompt](example/pilot-prompt.md) and [exit criteria](example/90-day-policy.md) to adapt the plan to an approved task in your environment. Do not upload private project data to a tool without authorization.

The example uses Python's standard library and writes only local ignored output files. Its dates, baseline, targets, and economics are invented teaching inputs, not observed Acme results or recommendations for a particular organization.
