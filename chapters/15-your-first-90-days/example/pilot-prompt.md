# Reader's 90-day pilot prompt

Use only a task and data source you are authorized to use. Start with a local, redacted example if approval is still pending. Do not paste private project records into a model to fill gaps in the plan.

1. Name one repetitive PM task, its decision owner, and the smallest output that would help. State what remains a human decision.
2. Record a manual baseline on comparable tasks, including total time and the quality rule for an accepted result.
3. Define an approved read-only source, review owner, stop conditions, and the tests a draft must pass. Specify what evidence would block the next phase.
4. Set a 60-day supervised trial target for accepted outputs and total time, including review, correction, and fallback.
5. At day 90, compare full cost, false alarms, reliability, and any delivery outcome actually measured. Choose continue, change, or retire, with the evidence that would reverse that decision.

The fictional Acme values in this repository are examples to replace, not defaults to trust. A plan generator can check that a charter is complete; it cannot verify organizational approval or declare a pilot successful.
